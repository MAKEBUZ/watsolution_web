# [T-008] Revocar refresh y cerrar cookie con acceso vencido

- **Hallazgos que resuelve:** WS-007. Resuelve la parte descrita; el hallazgo completo exige todas sus tareas de corrección en la matriz.
- **Prioridad / Fase / Esfuerzo:** P0 / F1 Contención inmediata / 12–20 h-persona. Estado: Pendiente. Responsable sugerido: Backend / líder técnico, nombre por asignar.
- **Contexto y riesgo si no se corrige:** Salir con el JWT vencido no revoca la cookie de renovación. El logout usa una instancia axios sin renovación y descarta el error. El backend exige AuthGuard antes de revocar y borrar cookie (session.controller.ts:22–26). Tras 15 minutos de inactividad el JWT puede expirar: el usuario ve salida, pero la cookie HttpOnly de siete días sigue válida y puede restaurar la cuenta al recargar.
