# [T-024] Habilitar recuperación pública segura de contraseña

- **Hallazgos que resuelve:** WS-004. Resuelve la parte descrita; el hallazgo completo exige todas sus tareas de corrección en la matriz.
- **Prioridad / Fase / Esfuerzo:** P1 / F2 Estabilización / 16–24 h-persona. Estado: Pendiente. Responsable sugerido: Backend / líder técnico, nombre por asignar.
- **Contexto y riesgo si no se corrige:** Las altas quedan sin un flujo funcional para obtener acceso. El alta administrativa crea cuenta inactiva con contraseña aleatoria desconocida. Activar desde administración no entrega una contraseña; la UI todavía dice que el teléfono será la contraseña (admin-usuarios.vue:516).
